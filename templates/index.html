Siap Menghitung
Petunjuk Penggunaan:
Cara Hitung Sendiri (Manual): 1. Klik tombol hijau "2. User Hitung Sendiri".
2. Arahkan mouse / sentuh jari ke setiap lubang pipa.
3. Nomor 1, 2, 3... langsung menempel pas di lubang pipa.
4. Klik kanan (atau tahan jari) untuk menghapus nomor yang salah.
Cara Dihitung Otomatis: Klik tombol biru "1. Dihitung Otomatis" jika ingin komputer menandai semua pipa secara otomatis terlebih dahulu.
